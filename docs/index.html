🛠️ coderun-tools Documentation

Standalone, multi-provider AI Agent tools library built in pure ESM JavaScript ("type": "module"). Designed for frictionless integration into any AI agent framework (OpenAI, Anthropic, Gemini, Ollama, VS Code extensions, or Node.js backends).

⚡ Universal SDK Compatibility: Supports built-in definition exports for OpenAI Agents SDK, Google Gemini ADK, LangChain / LangGraph, and raw OpenAI/Ollama tool calling.

Key Features

  • ES Modules (ESM): Native import / export API in plain JavaScript.
  • Framework Export Generators: Native helpers: getOpenAiAgentsDefinitions(), getGeminiAdkDefinitions(), getLangchainDefinitions().
  • Dual Terminal Execution Engine: Self-Executing Mode & Interactive Mode (15ms background execution).
  • Structured Task Planning: Create and update task checklists with status transitions (TODO ➔ WIP ➔ DONE).

Installation

npm install coderun-tools

🤖 Multi-SDK Framework Integration Guide

coderun-tools provides dedicated export functions so you can plug all 19 tools into any AI agent framework without writing adapter code.

1. OpenAI Agents SDK (`@openai/agents`)

Use getOpenAiAgentsDefinitions(tool) to generate tools formatted for `@openai/agents`:

import coderunTools, { getOpenAiAgentsDefinitions } from 'coderun-tools';
import { Agent, tool } from '@openai/agents';

var tools = getOpenAiAgentsDefinitions(tool);

var agent = new Agent({
  name: 'CodingAgent',
  instructions: 'You are a software engineering assistant.',
  tools: tools
});

2. Google Gemini ADK (`@google/adk`)

Use getGeminiAdkDefinitions() to generate tool objects for Google Gemini ADK's `FunctionTool` runner:

import coderunTools, { getGeminiAdkDefinitions } from 'coderun-tools';
import { FunctionTool } from '@google/adk';

var geminiTools = getGeminiAdkDefinitions({ FunctionTool: FunctionTool });

3. LangChain & LangGraph (`@langchain/core/tools`)

Use getLangchainDefinitions(tool) to generate tools for LangChain and LangGraph agent graphs:

import coderunTools, { getLangchainDefinitions } from 'coderun-tools';
import { tool } from '@langchain/core/tools';

var langchainTools = getLangchainDefinitions(tool);

4. CodeRun Agents SDK (`coderun-agent`)

Pass `getDefinitions()` directly to `createAgent`:

import coderunTools from 'coderun-tools';
import { createAgent } from 'coderun-agent';

var agent = createAgent({
  name: 'CodeAssistant',
  provider: 'openai-compatible',
  baseurl: 'http://localhost:11434/v1',
  model: 'qwen2.5-coder:7b',
  tools: coderunTools.getDefinitions()
});

1. `readFile` (`read_file`)

Reads the full contents of a file in the workspace.

var res = await coderunTools.readFile({ path: 'package.json' });

Success Output:

{
  "toolName": "readFile",
  "args": { "path": "package.json" },
  "output": { "success": true, "content": "...", "bytes": 443 }
}

2. `writeFile` (`write_file`)

Creates a file or overwrites an existing file, creating missing parent directories recursively.

var res = await coderunTools.writeFile({ path: 'src/app.js', content: 'console.log("Hello!");' });

Success Output:

{
  "toolName": "writeFile",
  "args": { "path": "src/app.js", "content": "console.log(\"Hello!\");" },
  "output": { "success": true, "content": "Wrote file 'src/app.js' successfully", "bytes": 21 }
}

3. `editFile` (`edit_file`)

Replaces a specific text block (oldText) with new text (newText).

var res = await coderunTools.editFile({ path: 'src/app.js', oldText: 'Hello!', newText: 'Hello World!' });

4. `patchFile` (`patch_file`)

Applies multiple search-and-replace patch blocks to a file in sequence.

var res = await coderunTools.patchFile({
  path: 'src/config.js',
  patches: [{ oldText: '3000', newText: '8080' }]
});

5. `deleteFile` (`delete_file`)

Deletes a single file permanently.

var res = await coderunTools.deleteFile({ path: 'scratch.tmp' });

6. `createFolder` (`create_folder`)

Creates a directory and any missing parent directories recursively.

var res = await coderunTools.createFolder({ path: 'src/utils/logs' });

7. `deleteFolder` (`delete_folder`)

Deletes a directory and all of its contents recursively.

var res = await coderunTools.deleteFolder({ path: 'dist' });

8. `listDirectory` (`list_directory`)

Lists all files and subdirectories inside a directory folder.

var res = await coderunTools.listDirectory({ path: 'src' });

9. `getFileInfo` (`get_file_info`)

Gets metadata (size, timestamps, entry type) for a file or directory.

var res = await coderunTools.getFileInfo({ path: 'package.json' });

10. `searchFiles` (`search_files`)

Recursively finds file paths matching a filename or extension pattern.

var res = await coderunTools.searchFiles({ pattern: 'readFile' });

11. `findInFiles` (`find_in_files`)

Searches for text content inside workspace files.

var res = await coderunTools.findInFiles({ query: 'formatResponse' });

12. `listSymbols` (`list_symbols`)

Extracts function and class symbol definitions from a code file.

var res = await coderunTools.listSymbols({ path: 'src/toolRegistry.js' });

13. `executeCommand` (`execute_command` / `run_terminal`)

Executes shell commands in self-executing mode or interactive mode (15ms background execution).

// Self-executing mode:
var res = await coderunTools.executeCommand({ command: 'node -v' });

// Interactive background process mode:
var serverRes = await coderunTools.executeCommand({ command: 'node app.js', isInteractive: true });

14. `terminalInput` (`terminal_input`)

Sends keyboard input string into an active background interactive process's stdin.

var res = await coderunTools.terminalInput({ processId: 44716, input: 'console.log(10);\n' });

15. `stopTerminal` (`stop_terminal`)

Stops/kills a running background interactive process by PID.

var res = await coderunTools.stopTerminal({ processId: 44716 });

16. `createPlan` (`create_plan`)

Initializes a checklist plan of execution tasks (initial status: "TODO").

var res = await coderunTools.createPlan({
  title: 'Express Setup',
  tasks: ['Initialize package.json', 'Create server.js']
});

17. `updatePlan` (`update_plan`)

Updates task status in an active plan (TODO ➔ WIP ➔ DONE).

var res = await coderunTools.updatePlan({ taskId: 1, status: 'DONE' });

18. `getCurrentDatetime` (`get_current_datetime`)

Returns the current system ISO timestamp string.

var res = await coderunTools.getCurrentDatetime();

19. `webRequest` (`web_request`)

Fetches HTTP/HTTPS web content.

var res = await coderunTools.webRequest({ url: 'https://api.github.com/zen' });
