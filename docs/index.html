🛠️ coderun-tools Documentation

Standalone, multi-provider AI Agent tools library built in pure ESM JavaScript ("type": "module"). Designed for frictionless integration into any AI agent framework (OpenAI, Anthropic, Gemini, Ollama, VS Code extensions, or Node.js backends).

⚡ Standardized Return Payload: Every single tool call resolves to a clean, deterministic object shape: { toolName, args, output }.

Key Features

  • ES Modules (ESM): Built natively using clean import and export syntax.
  • Dual Terminal Execution Engine:
    • Self-Executing Mode: Executes shell commands with live 300ms stream flushing.
    • Interactive Mode (isInteractive: true): Spawns background dev servers/REPLs immediately (15-30ms response) with PID tracking, live stream callbacks (onData), and stdin control (terminalInput).
  • Structured Task Planning: Create and update multi-step plans with automatic status transitions (TODO ➔ WIP ➔ DONE).
  • Universal Tool Registry: Exposes getDefinitions() (OpenAI/Ollama tool schemas) and executeTool(name, args) for dynamic tool dispatching.

Installation

npm install coderun-tools

Quickstart & Imports

ES Modules (ESM)

import coderunTools, { readFile, executeCommand, getDefinitions, executeTool } from 'coderun-tools';

// 1. Direct tool invocation:
var res = await coderunTools.readFile({ path: 'package.json' });
console.log(res.output.content);

// 2. Generic LLM tool execution:
var toolsSchema = getDefinitions();
var toolCallResult = await executeTool('read_file', { path: 'package.json' });

1. readFile (read_file)

Reads the full contents of a specified file path in the workspace.

var res = await coderunTools.readFile({ path: 'package.json' });

Success Output

{
  "toolName": "readFile",
  "args": { "path": "package.json" },
  "output": {
    "success": true,
    "content": "{\n  \"name\": \"coderun-tools\",\n  \"version\": \"1.0.1\"\n}",
    "file_path": "package.json",
    "bytes": 441
  }
}

2. writeFile (write_file)

Creates a file or overwrites an existing file, creating missing parent directories recursively.

var res = await coderunTools.writeFile({ path: 'src/app.js', content: 'console.log("Hello!");' });

Success Output

{
  "toolName": "writeFile",
  "args": { "path": "src/app.js", "content": "console.log(\"Hello!\");" },
  "output": {
    "success": true,
    "content": "Wrote file 'src/app.js' successfully",
    "file_path": "src/app.js",
    "bytes": 21
  }
}

3. editFile (edit_file)

Replaces a specific text block (oldText) with new text (newText) inside a file.

var res = await coderunTools.editFile({ path: 'src/app.js', oldText: 'Hello!', newText: 'Hello CodeRun!' });

4. patchFile (patch_file)

Applies multiple search-and-replace patch blocks to a file in sequence.

var res = await coderunTools.patchFile({
  path: 'src/config.js',
  patches: [{ oldText: '3000', newText: '8080' }]
});

5. deleteFile (delete_file)

Deletes a single target file permanently.

var res = await coderunTools.deleteFile({ path: 'scratch.tmp' });

6. createFolder (create_folder)

Creates a directory and any missing parent directories recursively.

var res = await coderunTools.createFolder({ path: 'src/utils/logs' });

7. deleteFolder (delete_folder)

Deletes a directory and all of its contents recursively.

var res = await coderunTools.deleteFolder({ path: 'dist' });

8. listDirectory (list_directory)

Lists all files and subdirectories inside a directory folder.

var res = await coderunTools.listDirectory({ path: 'src' });

9. getFileInfo (get_file_info)

Gets metadata (file size, creation timestamp, modification timestamp, entry type) for a file or folder.

var res = await coderunTools.getFileInfo({ path: 'package.json' });

10. searchFiles (search_files)

Recursively finds file paths matching a filename pattern or extension in the workspace.

var res = await coderunTools.searchFiles({ pattern: 'readFile' });

11. findInFiles (find_in_files)

Searches for text content occurrences inside workspace files.

var res = await coderunTools.findInFiles({ query: 'formatResponse' });

12. listSymbols (list_symbols)

Extracts function, class, and method symbol definitions with line numbers from a code file.

var res = await coderunTools.listSymbols({ path: 'src/toolRegistry.js' });

13. executeCommand (execute_command / run_terminal)

Executes shell commands in self-executing mode or interactive mode (isInteractive: true).

// Self-executing command:
var res = await coderunTools.executeCommand({ command: 'node -v' });

// Interactive background server command (returns PID in 15ms):
var serverRes = await coderunTools.executeCommand({ command: 'node server.js', isInteractive: true });

14. terminalInput (terminal_input)

Sends keyboard input string into a running background interactive process's stdin.

var res = await coderunTools.terminalInput({ processId: 44716, input: 'console.log("hi");\n' });

15. stopTerminal (stop_terminal)

Stops/kills a running background interactive process by PID.

var res = await coderunTools.stopTerminal({ processId: 44716 });

16. createPlan (create_plan)

Initializes a plan with execution tasks (initial task state: "TODO").

var res = await coderunTools.createPlan({
  title: 'Setup Project',
  tasks: ['Initialize package.json', 'Create src/index.js']
});

17. updatePlan (update_plan)

Updates task status in an active plan (TODO ➔ WIP ➔ DONE).

var res = await coderunTools.updatePlan({ taskId: 1, status: 'DONE' });

18. getCurrentDatetime (get_current_datetime)

Gets current system date, time, and ISO timestamp.

var res = await coderunTools.getCurrentDatetime();

19. webRequest (web_request)

Performs HTTP GET/POST network requests with headers and payload.

var res = await coderunTools.webRequest({ url: 'https://api.github.com/zen' });
